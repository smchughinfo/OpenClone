**Windows Development:**

1. Install VS Code Theme [Dracula Theme](https://vscodethemes.com/e/dracula-theme.theme-dracula/dracula-theme)
2. [Install Python 3.9.13](https://www.python.org/downloads/release/python-3913/)
3. .venv\Scripts\activate
4. pip3 install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu118
5. pip install -r requirements.txt
6. Download checkpoints zip file. Extract. Move to /OpenClone/OpenVoice/checkpoints
